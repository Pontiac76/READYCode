# Keyboard Shortcuts

A reference for every keyboard shortcut in READYCode, grouped by category. Most are also available from the menu bar or a right-click context menu if you would rather not memorize them.

## File

| Shortcut | Action |
| --- | --- |
| Ctrl+N | New Program File |
| Ctrl+Alt+N | New Assembly File |
| Ctrl+O | Open File... |
| Ctrl+K, Ctrl+O | Open Folder... |
| Ctrl+Shift+T | Reopen Closed Tab |
| Ctrl+F4 | Close Editor |
| Ctrl+K, F | Close Folder |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save As... |
| Ctrl+P | Print... |

## Editing

| Shortcut | Action |
| --- | --- |
| Ctrl+Z | Undo |
| Ctrl+Y | Redo |
| Ctrl+X | Cut |
| Ctrl+C | Copy |
| Ctrl+V | Paste |
| Delete | Delete selection |
| Ctrl+K, Ctrl+C | Comment Selection |
| Ctrl+K, Ctrl+U | Uncomment Selection |
| Ctrl+Shift+U | Make Uppercase |
| Ctrl+M | Minify Code |
| Ctrl+Shift+M | Prettify Code |
| Ctrl+R | Renumber Code |
| F2 | Rename (variable, label, or Explorer item) |

## Find and navigate

| Shortcut | Action |
| --- | --- |
| Ctrl+F | Find |
| Ctrl+H | Replace |
| Ctrl+Shift+F | Find in Files |
| Ctrl+Shift+H | Replace in Files |
| Ctrl+G | Go to Line... |
| F12 | Go to Definition (from a GOTO/GOSUB/THEN target) |

## Tabs

| Shortcut | Action |
| --- | --- |
| Ctrl+Tab | Next tab |
| Ctrl+Shift+Tab | Previous tab |
| Ctrl+F4 | Close current tab |
| Ctrl+K, U | Close all saved tabs |
| Ctrl+K, W | Close all tabs |

## View

| Shortcut | Action |
| --- | --- |
| Ctrl+B | Toggle Primary Side Bar |
| Ctrl+Alt+B | Toggle Secondary Side Bar |
| Ctrl+Shift+E | Show Explorer |
| Ctrl+Alt+V | Toggle Variables panel |
| Alt+Z | Toggle Word Wrap |

## Running your program

| Shortcut | Action |
| --- | --- |
| F5 | Run on C64 Ultimate |
| Ctrl+F5 | Load on C64 Ultimate |
| Alt+F5 | Run on VICE |
| Ctrl+Alt+F5 | Load on VICE |

See [Transferring to Hardware and Emulators](c64-ultimate-and-vice.md) for what these do.

## Inserting PETSCII characters (Quick Keys)

| Shortcut | Action |
| --- | --- |
| Ctrl+1 through Ctrl+8 | Screen control codes (clear, home, cursor keys, reverse) |
| Ctrl+Shift+1 through Ctrl+Shift+8, Ctrl+Shift+Alt+1 through Ctrl+Shift+Alt+8 | The sixteen color codes |
| Shift+F1 through Shift+F8 | Function-key codes |

See [The BASIC Editor](basic-editor.md#the-petscii-reference-panel) for the equivalent clickable reference panel.
